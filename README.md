# Haze-Busting Consultancy Services — Website (Option 1 · v0.3)

Static website (HTML, CSS and JavaScript — no build step needed to view it).

**Option:** Option 1 · v0.3 — Option 1 uses a dark full-bleed city-towers hero photo.

## How to view
- Download or clone this repository and open `index.html` in a browser.
- Pages: Home, About Us, HR Services, Other Services (Recruitment · HR Certification Course), Contact Us.
- An internet connection is needed for web fonts, smooth-scroll/animation libraries and the Contact map.

## Structure
```
index.html · about.html · hr-services.html · other-services.html · contact.html
css/style.css     styles
js/main.js        interactions and animation
assets/           logo, founder photo and images
tools/build.js    page generator (Node.js) — `node tools/build.js`
```
